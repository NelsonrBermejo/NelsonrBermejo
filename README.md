### About Me

I take ownership of what I commit to, I enjoy communicating clearly, and I'm always looking for opportunities to learn and grow. I work in an organized way and like to understand how what I build works.

- 🌐 Developed the frontend of [Hora de Alquilar](https://www.horadealquilar.com.ar/), a `production website`: search filters by area and capacity, property listings with photos, and `Google Maps API` integration
- 📱 Adapted an `Android` app in `Java` that connects via Bluetooth to a device to display vehicle faults, and implemented screens with charts
- 🏥 Built file upload for `DICOM` files (medical images) with `Node.js`, and a page with `Angular` within an existing application
- 🗄️ Worked with APIs and databases (`PostgreSQL`, `MySQL` and `MongoDB`), and I'm continuing to deepen my `SQL`
- 🔄 Trained in agile methodologies and worked alongside other developers
- 🛠️ Still working on Hora de Alquilar, which is live, with updates and improvements when requested
- 🚀 Continuing to grow as a developer
- 🤝 Open to new `opportunities` as a `junior` developer
